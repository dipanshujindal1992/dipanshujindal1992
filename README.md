## About Me

I'm **Dipanshu Jindal**, a mobile app developer and technology leader focused on building reliable, scalable digital products.

My work spans mobile application engineering, backend integrations, application architecture, and the journey from an initial product concept to a production release.

I enjoy solving complex engineering problems, creating maintainable software, and helping teams deliver products that provide real value to users.

- 📱 **Mobile development:** React Native, Flutter, Android and iOS
- 🏗️ **Software architecture:** Maintainable codebases, scalable application design and integrations
- 🔌 **Backend engineering:** REST APIs, Node.js, Firebase and cloud-connected applications
- 🚀 **Product delivery:** Development, testing, performance optimization and release readiness
- 🤝 **Engineering leadership:** Technical planning, collaboration and delivery

> My philosophy: build for reliability, design for maintainability, and optimize for the people using the product.
